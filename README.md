# FactoryOS Mockup

FactoryOS Mockup is an interactive prototype of a unified Business Operating System for factory and industrial trading operations.

The purpose of this project is to demonstrate how product data, inventory, quotations, invoices, customers, and reporting can be unified into one platform.

## Tech Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- Recharts
- Mock data only

## Core Modules
- Dashboard
- Product Master
- Inventory
- Quotations
- Invoice Management
- Customer Management
- Reports
- Settings

## Project Goal
This is not a production ERP system.
This is a client-facing mockup used to present the vision of a unified Business Operating System.

## Getting Started
```bash
npm install
npm run dev
```

Open:
[http://localhost:3000](http://localhost:3000)

## Deployment
This project is designed to be deployed on Vercel.

## Folder Structure
- `app/` - Page Routing and App Layout
- `components/` - Reusable UI Components
- `data/` - Static Mock Data for Products, Customers, Quotes, Invoices
- `lib/` - Shared types, calculation functions, and utilities
- `docs/` - Project documentation and guides

## Notes
All data is mocked. No database, authentication, or external API is required in this version.
All pages are fully responsive and designed for clean B2B presentation.
