# Project Context

## Overview
FactoryOS Mockup is an interactive prototype for a unified Business Operating System.

The business problem is that many factories and industrial trading companies use disconnected tools for daily operations.

Common current workflow:
- Power BI for reports
- Separate software for invoices
- Separate software for quotations
- Manual stock counting
- Excel-based data entry
- Manual document preparation
- Scattered product and customer data

This creates duplicated work, slow reporting, inconsistent data, and limited real-time visibility.

## Product Vision
FactoryOS aims to become a single platform where the business can manage core operations from one place.
The platform should eventually replace or reduce dependency on multiple disconnected tools.

## Mockup Goal
The current version is not a production system.
The goal is to help the client see:
- What a unified platform could look like
- How departments can work together in one system
- How product, stock, quotation, invoice, and reporting data can connect
- How management can view business performance from one dashboard

Needs:
- Revenue overview
- Sales performance
- Inventory value
- Outstanding invoices
- Low stock alerts
- Business reports

### Sales Team
Needs:
- Product catalog
- Customer database
- Quotation creation
- Quotation tracking
- Invoice status

### Warehouse / Inventory Team
Needs:
- Stock quantity
- Stock movement
- Low stock warning
- Receive stock
- Issue stock
- Adjust stock

### Accounting / Finance
Needs:
- Invoice list
- Payment status
- Outstanding balance
- Tax information
- Document numbering

### Admin
Needs:
- Company settings
- User roles
- Permission control
- Document templates

## Core Business Flow
The main business flow should be:
```
Product Master -> Inventory -> Quotation -> Invoice -> Reports -> Dashboard
```

## Domain Details
The mockup should focus on industrial cable products.

Example product attributes:
- SKU
- Product name
- Category
- Cable type
- Core
- Size
- Voltage
- Color
- Unit
- Cost
- Selling price
- Stock quantity
- Minimum stock
- Status
- Datasheet

Example products:
- CV 1x50 sq.mm 0.6/1kV
- CV 1x95 sq.mm 0.6/1kV
- NYY 4x16 sq.mm 0.6/1kV
- VCT 4x2.5 sq.mm
- THW 1x10 sq.mm
- Control Cable 12 Core 1.5 sq.mm

## Presentation Positioning
This mockup should communicate:
“FactoryOS is a unified business platform that connects product data, stock, sales documents, invoices, and reports into one operating system.”

Do not position it as a finished ERP.
Position it as:
- Business Operating System
- Unified factory platform
- Digital operation hub
- Future-ready internal platform

## Success Criteria
The mockup is successful if the client can open the website and quickly understand:
- What modules exist
- How the system works
- How quotation and invoice data connects to products and stock
- How reports and dashboards are generated from operational data
- How this could replace fragmented software in the future
