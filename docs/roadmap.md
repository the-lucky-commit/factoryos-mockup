# Roadmap

## Phase 0: Interactive Mockup
Goal:
Create a clickable mockup to demonstrate the business platform concept.

Features:
- Dashboard
- Product Master
- Inventory
- Quotations
- Invoices
- Customers
- Reports
- Settings
- Mock data
- Document preview

No backend required.

## Phase 1: Internal Prototype
Goal:
Convert mockup into a working internal prototype.

Features:
- Database
- Authentication
- Role-based access
- Real product data
- Real customer data
- Real quotation creation
- Real invoice records

Possible stack:
- Next.js
- PostgreSQL
- Prisma
- Supabase or Neon
- NextAuth or Clerk

## Phase 2: Business Workflow Platform
Goal:
Support real daily operations.

Features:
- Stock movement
- Quotation approval
- Invoice generation
- PDF export
- Customer history
- Activity logs
- Document numbering
- Import Excel / CSV

## Phase 3: Factory Operating System
Goal:
Expand into deeper factory operations.

Features:
- Purchase orders
- Supplier management
- Production planning
- BOM (Bill of Materials)
- Job orders
- Warehouse locations
- Barcode / QR code support
- Advanced reporting

## Phase 4: Full Business Intelligence
Goal:
Replace scattered reporting tools.

Features:
- Management dashboard
- Advanced analytics
- Sales forecast
- Inventory forecast
- Customer performance
- Product profitability
- Export reports
- Optional Power BI integration
